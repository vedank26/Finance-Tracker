## Privacy

Public copies remove browser address bars where the live server IP appeared. Usernames, email addresses, transaction descriptions/counterparties, exact financial amounts and personal score details are hidden in the public images. Keep original screenshots only in private storage; do not commit unredacted originals.

These screenshots illustrate the application's interface. They do not independently prove that cloud resources remain active.
